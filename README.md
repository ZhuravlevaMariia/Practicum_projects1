# Practicum_projects1
Проект: Автоматизация процесса оформления заказов для интернет-магазина «Переделкино»
📌 Описание проекта
Данный проект направлен на реинжиниринг и автоматизацию бизнес-процессов интернет-магазина стройматериалов и товаров для дома «Переделкино». Основная цель исследования — переход от ручной обработки заказов (модель «AS IS») к полностью автоматизированной системе (модель «TO-BE»).

В ходе работы были спроектированы архитектура решения, пути клиента (CJM) и логика бизнес-процессов (BPMN). Ключевая задача — сократить время обработки одного заказа с 1 рабочего дня до 1 часа, а также снизить нагрузку на администраторов и минимизировать количество неподтвержденных заказов.

📊 Исследуемый набор данных
Проект базируется на реальных операционных данных магазина, предоставленных заказчиком в формате Excel-таблиц. В качестве входных данных для исследования использовались:

Статистика продаж (за последние 3 месяца): данные о количестве проданных единиц, ценах и себестоимости товаров.

Карточки товаров и таблица поставщиков: номенклатура, артикулы и логистические данные.

Данные клиентов: клиентская база, содержащая статусы заказов (в т.ч. выявлена проблема большого числа заказов со статусом «Не подтверждён»).

Тарифы и данные о сотрудниках: для настройки ролей и расчета стоимости дополнительных услуг (сборка мебели, подъём на этаж).

🎯 Основные пункты и цели исследования
Обследование текущего состояния (AS IS): Выявлены ключевые «узкие места»: отсутствие поиска и фильтрации на сайте, ручная связь администратора со складом по телефону, сбои в сервисе онлайн-оплаты.

Проектирование целевого состояния (TO-BE): Разработка архитектуры интеграции сайта со складской системой через REST API и проектирование личного кабинета пользователя.

Внедрение MVP (Минимально жизнеспособного продукта): Реализация ключевого функционала: чат-бот для клиентов, онлайн-оплата со скидкой 5% и автоматическое резервирование товаров.

Разработка пользовательской документации: Создание руководства пользователя и программы обучения для сотрудников магазина и клиентов.

Целевые метрики эффективности: сокращение времени обработки заказа до 1 часа, увеличение доли повторных покупок на 30%, повышение конверсии из корзины в заказ на 25%.

🛠️ Используемые технологии и библиотеки (в рамках проектирования)
В ходе выполнения аналитической части проекта использовались следующие инструменты:

Miro — для построения карт пути клиента (CJM) и прототипирования интерфейсов.

Draw.io — для моделирования бизнес-процессов в нотации BPMN.

Microsoft Excel / Google Sheets — для первичного анализа предоставленных коммерческих таблиц.

(Примечание: при разработке программной реализации проекта в стеке Python гипотетически могли бы использоваться библиотеки для работы с таблицами — pandas, openpyxl, а также для бэкенда — FastAPI или Django для реализации REST API интеграции. В рамках данной работы непосредственно кодовая реализация не входила в этап бизнес-обследования).
